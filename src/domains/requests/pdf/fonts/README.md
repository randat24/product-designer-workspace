Static TTF instances of Manrope (400, 500, 600, 700) and IBM Plex Mono (400) from Google Fonts, full character sets
(Latin and Cyrillic, including Ukrainian і, ї, є, ґ). Manrope 500 is instanced from the variable Manrope[wght].ttf
with fontTools (`varLib.instancer wght=500`). Used by the project brief PDF (@react-pdf/renderer needs TTF; the
site's woff2 subsets do not work there). License: SIL Open Font License 1.1.
