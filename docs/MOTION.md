# Движение и отклик: спецификация для разработки

Правила, по которым сайт (SIGNAL) и инструмент отвечают на действия пользователя. Короткая версия — в `DESIGN-SYSTEM.md`, раздел «Движение и отклик»; здесь всё, что нужно, чтобы сделать новый экран так же.

## Обзор

- **Цель:** любое действие получает видимый ответ меньше чем за 120 мс, даже если сервер отвечает дольше.
- **Принцип:** движение подтверждает действие или показывает ожидание, а не украшает.
- **Уменьшенная анимация:** всё описанное выключается при `prefers-reduced-motion: reduce`. Исключение — крутилка: это состояние, а не украшение. Она останавливается, но остаётся видна.
- **Код:** `src/app/globals.css`, `src/site/signal/signal.css`, `src/shared/ui/`.

## Единицы

- Все размеры в `rem`: N px = N/16 rem. Корневой размер шрифта нигде не переопределяется, поэтому при шрифте браузера 16 px вёрстка совпадает с пиксельной.
- В `px` остаются только линии толщиной 1 px и меньше, рамки, обводки фокуса, тени, отступы подчёркивания, blur, атрибут `sizes` у картинок (по нему браузер выбирает файл по ширине в пикселях) и генераторы OG и PDF.
- **Зачем:** при увеличенном шрифте в браузере вместе с текстом растут и отступы, и кнопки.

## Токены

| Токен | Значение | Где |
|---|---|---|
| `--duration-fast` | 120ms | нажатие, наведение, смена цвета |
| `--duration-base` | 220ms | появление, исчезновение, подпрыгивание счётчика |
| `--ease-standard` (класс `ease-standard`) | `cubic-bezier(.2, .7, .3, 1)` | все переходы: быстрый старт, мягкая посадка |
| `--sg-duration-fast/base` | `var(--duration-*)` | алиасы сайта, отдельных значений нет |

При уменьшенной анимации оба токена длительности равны `0ms`. Чисел в коде не пишем, только `duration-(--duration-fast)` и `var(--duration-base)`.

## Состояния и взаимодействия

| Элемент | Состояние | Поведение |
|---|---|---|
| Кнопка действия | ожидание | Крутилка, цвет сохраняется. Если одно ожидание блокирует несколько кнопок, крутится **только нажатая**: храните, какая кнопка нажата (так сделано в `notes/composer.tsx` и `competitors/matrix.tsx`). |
| Ссылка внутри приложения | клик | Если страница не открылась за 120 мс, появляется полоса. Она растёт до 85% за 8 с, всё медленнее. Когда новая страница на месте, доходит до 100% и гаснет. Если страница так и не открылась, полоса исчезает через 10 с. |
| Ссылка на файл | клик | Полосы нет. Это ссылки с `download`, `data-no-progress` или расширением в пути (`.xml`, `.pdf`). Ссылки на файлы без `download` помечайте `data-no-progress`. |
| `role="alert"` / `role="status"` | вставка | Проявление за `--duration-base`, только прозрачностью. Если текст меняется внутри уже существующего элемента, анимации нет (`@starting-style`). |
| Новая запись (мгновенный результат) | до ответа сервера | Видна сразу, приглушена (`opacity-60`), с `aria-busy`, не нажимается (`pointer-events-none`). id временный, вида `pending:…`. Ключ React не должен зависеть от этого id, иначе элемент анимируется дважды. Примеры: `design/states-panel.tsx`, `synthesis/board.tsx`. |
| Изменение (переключатель, удаление) | ошибка сервера | Возвращается исходное состояние и показывается сообщение через `role="alert"`. |
| Счётчик реакции | изменение | Импульс `translateY(-3px) scale(1.25)` на 40% длительности, только у реакций, которые посетитель менял на этой странице. При первой отрисовке импульса нет. |

## Адаптивность

| Ширина | Что меняется |
|---|---|
| ≥64rem (`lg`) | Навигация сайта в одну строку в шапке. |
| <64rem | Ссылки навигации переходят на вторую строку шапки, меню-гамбургера нет. |
| ≤56.25rem | Шапка кейса в одну колонку `minmax(0, 1fr)`. |
| ≤40rem | Сетки в одну колонку. |
| ≤30rem | Подписи кнопок сайта могут переноситься. |
| Любая ширина при крупном шрифте | Имя в шапке может перенестись на вторую строку, длинные слова переносятся (`overflow-wrap: break-word`). |

**Правило для новых сеток:** одна колонка — это `minmax(0, 1fr)`, а не `1fr`. Колонка `1fr` не сжимается уже самого длинного слова и выдавливает страницу за край экрана.

## Пограничные случаи

- **Медленная сеть:** полоса прогресса, крутилка в кнопке, мгновенный результат с откатом. Старая страница при переходе на сайте держится максимум 600 мс, дальше меняется без анимации.
- **Без View Transitions** (Firefox): ссылки работают как обычно, без наплыва и перелёта обложки.
- **Без scroll-driven animations:** блоки стоят на месте, появления при прокрутке нет.
- **Элементы, которые пересоздаются целиком:** `.enter` не ставить. Пример — доска синтеза: она перемонтируется после каждого перемещения карточки, и анимация проиграется на всех карточках разом.
- **Длинный текст:** переносится. Обрезка многоточием только там, где указана явно (например, превью заметки в списке инструмента, `line-clamp-3`).
- **Известное ограничение:** на экране 320 px со шрифтом браузера 24 px отдельные длинные слова в заголовках кейса (например, «Медіаменеджер») не помещаются в строку.

## Анимации

| Элемент | Триггер | Анимация | Длительность | Кривая |
|---|---|---|---|---|
| Кнопки, иконки, чипы | `:active` | сдвиг на 1 px / `scale(.95)` / `scale(.97)` | 120ms | `--ease-standard` |
| Полоса прогресса | клик → новая страница | `scaleX` 0 → 0.85 → 1 от левого края (не ширина: без пересчёта раскладки), затем гаснет | 8s → 220ms | `cubic-bezier(.1, .7, .2, 1)` → `--ease-standard` |
| Сообщения | вставка в DOM | прозрачность 0 → 1 | 220ms | `--ease-standard` |
| `.enter` | вставка в DOM | прозрачность + подъём на 0.375rem | 220ms | `--ease-standard` |
| Переход страниц сайта | клик по внутренней ссылке | наплыв | 220ms | по умолчанию |
| «Слід рішень» в герое | загрузка | записи поднимаются одна за другой с шагом `--duration-fast / 2`, затем огонёк трижды пробегает по линии и останавливается | `--duration-base` на запись; огонёк 3.2s × 3 | `--ease-standard` |
| Скриншоты в карточке работы | наведение мышью (только `hover: hover` и `pointer: fine`) | поворот и сдвиг | `--duration-base` | `--ease-standard` |
| Обложка кейса | карточка → кейс | перелёт через `view-transition-name: case-<slug>` (одно имя у карточки и у обложки кейса) | 360ms | `--ease-standard` |
| Блоки сайта | прокрутка | подъём на 2rem, **только сдвиг, без прозрачности** | диапазон `entry 0%–60%` | linear |
| Заголовок героя (`.sg-line`) | загрузка | строки выезжают из-под своего нижнего края, **без прозрачности**, каждая следующая на `--duration-fast` позже | `--duration-base` на строку | `--ease-standard` |
| Заголовки разделов (`.sg-heading .sg-line`) | прокрутка | то же по строкам, вторая строка позже | диапазон `entry 0%–70%` и `entry 20%–100%` заголовка | linear |
| Счётчик реакции | изменение | подпрыгивание | 220ms | `--ease-standard` |

У появления при прокрутке нет прозрачности намеренно: полупрозрачный текст не проходит проверку контраста и хуже читается.

## Доступность

- Полоса прогресса декоративная (`aria-hidden`). Новую страницу объявляет она сама.
- Кнопка в ожидании получает `aria-busy`. Фокус с неё не уходит.
- Сообщения идут через `role="alert"` (ошибки) и `role="status"` (успех). Анимируются только прозрачностью, поэтому читалка экрана объявляет их сразу.
- Ссылка-картинка в карточке кейса скрыта от читалок и клавиатуры (`aria-hidden`, `tabindex=-1`). У картинки есть `alt` для поисковиков, а читалки получают ссылку из заголовка.
- При уменьшенной анимации все движения выключены, кроме самой крутилки: она останавливается, но остаётся видна.
