# ADR-0006 · Человекочитаемые коды сущностей

Статус: **Accepted** (Phase 1) · Дата: 2026-09-29

Коды (`INS-012`, `P07`, `DEC-024`) выдаёт `next_code(project, type)`: атомарный `insert … on conflict do update` по `project_counters`, формат (префикс, разделитель, ширина) — из `entity_types`. Для таблиц с колонкой `code` триггер `assign_code` подставляет код автоматически. Коды уникальны в пределах проекта, используются в URL, поиске и упоминаниях. Номера не переиспользуются после удаления — это сохраняет смысл старых ссылок в Slack и Figma.
