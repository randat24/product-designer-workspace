# Design System — самого приложения

Статус: Draft v0.1 · Это дизайн-система интерфейса Product Designer Workspace (не модуль «Design System» внутри проектов пользователя).

## 1. Направление

Серьёзный профессиональный инструмент: плотность, ясная иерархия, скорость, клавиатура. Философия — Linear, Notion, Figma, FigJam, Dovetail; визуально не копируем.

**Делаем:** плотные таблицы и списки, типографическая иерархия вместо карточек, цвет как смысл (тип сущности, статус, severity), видимые связи.
**Не делаем:** крупные декоративные карточки, градиенты, маркетинговые дашборды, большие заголовки, анимации ради анимаций, «AI-first» паттерны (искры, чат-поле на главном экране).

**Фирменный элемент** — *trace-цепочка*: компактная линия из цветных entity-чипов `Q-041 → INS-012 → PP-008 → OPP-005 → SCR-031`. Это единственный «запоминающийся» визуальный мотив; всё остальное сдержанно.

**Цвета типов сущностей** (приглушённые, используются в чипах и индикаторах; контраст текста ≥ 4.5:1):

Цвета участников на доске синтеза и в матрице — палитра из 8 пастельных оттенков (отсылка к стикерам исследования), только как фон ячеек/карточек.

### Типографика
- Шрифт интерфейса: **Inter** (полная кириллица, табличные цифры `tnum`). Моноширинный для кодов сущностей не используется — коды набираются Inter с `tnum` и medium-весом.
- Базовый размер 14px (плотность), чтение длинного текста (интервью, спецификации) — 15px/24px.

| Стиль | Size / Line | Weight | Где |
|---|---|---|---|
| Title | 20 / 28 | 600 | Заголовок страницы (не больше) |
| Heading | 16 / 24 | 600 | Секции |
| Subheading | 14 / 20 | 600 | Группы полей, заголовки колонок |
| Body | 14 / 20 | 400 | Интерфейс |
| Body Long | 15 / 24 | 400 | Ответы интервью, rich text |
| Small | 13 / 18 | 400 | Метаданные |
| Caption | 12 / 16 | 500 | Счётчики, чипы |

### Отступы, радиусы, тени
- Сетка 4px: `4, 8, 12, 16, 24, 32, 48`.
- Высота строки таблицы: 32px (compact) / 40px (comfortable) — переключатель плотности.
- Радиусы: 4 (чипы, поля), 6 (кнопки, поповеры), 8 (модалки). Без «пилюль» везде подряд.
- Тени только у всплывающих слоёв (popover, dialog, command palette); панели разделяются бордерами.

### Motion
- 120 мс — hover/press, 180 мс — поповеры, 240 мс — панели (ease-out). Анимация только в ответ на действие. `prefers-reduced-motion` → без переходов.

## 3. Компоненты

**Базовые (shadcn/ui, перестилизованные):** Button, IconButton, Input, Textarea, Select, Combobox, Checkbox, Radio, Switch, Tabs, Dialog, Sheet, Popover, Tooltip, Toast, DropdownMenu, Table, Badge, Avatar, Skeleton.

**Продуктовые:**
| Компонент | Назначение |
|---|---|
| `EntityChip` | Код + цвет типа + название по hover; клик — переход; основа trace-цепочки |
| `TraceChain` | Горизонтальная цепочка чипов upstream → текущая → downstream |
| `TracePanel` | Правая панель: Upstream / Downstream / «Связать…» / Unsupported |
| `LinkPicker` | Combobox выбора сущностей с фильтром по допустимым типам |
| `EvidenceList` | Цитаты с участником, интервью, датой; выделение текста-источника |
| `UnsupportedBadge` | Нейтральный предупреждающий маркер «нет источников» |
| `InlineField` | Поле, редактируемое по месту (click / Enter), автосохранение |
| `PropertyPanel` | Колонка свойств detail-страницы (статус, severity, код, даты) |
| `StatusPill` / `SeverityPill` | Статусы и severity в единых цветах |
| `MatrixGrid` | Виртуализированная матрица (Question × Participant, Feature × Product, Task × Session) |
| `SynthesisBoard` | Колонки-кластеры с карточками (DnD, клавиатурное перемещение) |
| `FlowCanvas` + набор узлов | React Flow: Start, Screen, Action, Decision, System, Error, Success, End |
| `StageProgress` | Индикатор этапов ✓ ● ○ на дашборде |
| `NextActionItem` | Строка «что сделать» со ссылкой на сущность |
| `MethodHint` | Ссылка «Как это делать» на Knowledge |
| `EmptyState` | Объясняет метод и даёт одно главное действие |
| `CommandPalette` | ⌘K: навигация, создание, связывание |

## 4. Клавиатура

| Клавиши | Действие |
|---|---|
| ⌘K | Command palette |
| ⌘. | Показать/скрыть Trace panel |
| C | Создать сущность в текущем разделе |
| L | Связать текущую сущность… |
| J / K | Вниз / вверх по списку |
| Enter / Esc | Открыть / закрыть |
| G затем I / P / O / S / D | Перейти: Insights / Pain points / Opportunities / Screens / Decisions |
| Q (выделен текст ответа) | Создать цитату |
| O (выделен текст / цитата) | Создать наблюдение |

## 5. Доступность

WCAG 2.2 AA: контраст ≥ 4.5:1 для текста, видимый фокус (2px `accent`), все DnD-операции дублируются клавиатурой и меню «Переместить в…», цвет никогда не единственный носитель смысла (чипы содержат код и иконку типа), aria-live для автосохранения, корректные landmark-ы (nav, main, complementary для Trace panel).

## 6. Адаптивность

| Ширина | Поведение |
|---|---|
| ≥ 1280 | Sidebar + main + Trace panel |
| 1024–1279 | Trace panel поверх контента (sheet) |
| 768–1023 | Sidebar сворачивается в иконки; матрицы скроллятся внутри контейнера; flow — просмотр и базовое редактирование |
| < 768 | Нижняя навигация по группам; списки вместо таблиц; flow — вертикальный список шагов; полноценны live-интервью и быстрый ввод наблюдений |

## 7. Тон интерфейса

Интерфейс на RU/UK/EN (i18n с первого дня, строки в словарях). Кнопки называют действие («Создать инсайт», «Связать с экраном»), пустые состояния объясняют метод в одном предложении и дают одно действие. Ошибки говорят, что случилось и как исправить, без извинений.
